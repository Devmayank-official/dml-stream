## Overview

YouTube Downloader Terminal is an enterprise-level Python application for downloading YouTube videos, audio, and playlists. It features:

- Modular architecture with clean separation of concerns
- Type-safe code with full type hints
- Comprehensive error handling and logging
- Multi-threaded downloads for maximum speed
- Scheduled and batch download capabilities
- Beautiful CLI interface with Rich

## Getting Started

```bash
# Install
pip install youtube-downloader-terminal

# Run interactive mode
youtube-downloader interactive

# Download a video
youtube-downloader download --url "https://youtube.com/watch?v=..."
```

For more information, see the [User Guide](user-guide.md).
